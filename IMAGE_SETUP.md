# 🖼️ Image Setup Guide

You need to download images from your Wix site and save them in the `images/` folder with the names below. The easiest way: right-click each image on your Wix site → "Save image as..." → rename it.

## Hero / About Images
| Save as...              | Source (from your Wix site)        |
|-------------------------|------------------------------------|
| `hero-1.jpg`            | First photo on Home page (portrait of you) |
| `hero-2.jpg`            | Second photo on Home page          |
